# Guara 0.1.3

Guara 0.1.3 brings the new maned wolf identity, clearer onboarding, reliable connection cleanup,
and a tested, complete installation bundle. Python distribution and CLI names remain `opentruth`.

## Changes

- A documentation index and Brazilian Portuguese getting-started guide.
- Clearer runtime/development installation, Windows activation, and workspace selection.
- Consolidated current backup, integrity, pagination, and reassessment guidance.
- Guará, a Brazilian maned wolf mascot, with usage and accessibility guidance.
- DOI citation metadata: [10.5281/zenodo.23870405](https://doi.org/10.5281/zenodo.23870405).
- `opentruth --version` reports the installed distribution version without opening a store.
- `with OpenTruth(workspace) as app:` closes the SQLite connection on success and exceptions.
- Local Markdown/image-link validation and installed-wheel CLI validation.
- Automated complete ZIP and SHA-256 manifest generation from validated wheel/source inputs.
- Packaging regressions reject mismatched versions, duplicate files, traversal, symlinks, and nested old deliveries.
- English LinkedIn artwork with a prominent repository link.

## Compatibility

No schema change: schema 2, evidence statuses, JSON CLI defaults, and the twelve MCP tools
are preserved. Python 3.11+ is required. Runtime remains offline after dependency installation.
Secure local source ingestion remains POSIX-only; Windows supports metadata workflows.

Back up existing evidence before upgrading. Install the supplied wheel with
`python -m pip install /path/to/opentruth-0.1.3-py3-none-any.whl`, then run
`opentruth --version`. See the [installation guide](../installation.md).

The product and remote repository are named Guara. The owner completed the remote rename,
confirmed through GitHub API. See [compatibility details](../repository-name.md).

See the [local validation results](v0.1.3-validation.md) for the checks executed on this deliverable.

## Downloads

Use `Guara-0.1.3.zip` for the complete product, or install `opentruth-0.1.3-py3-none-any.whl`
in a Python 3.11+ virtual environment. `SHA256SUMS` covers each downloadable artifact.
The ZIP contains a `Guara/` directory; open `COMECE-AQUI.md` after extraction.

CI gates publication on Linux, macOS, and Windows with Python 3.11–3.13. PyPI publication
is a separate, optional maintainer workflow and is not part of this release.
