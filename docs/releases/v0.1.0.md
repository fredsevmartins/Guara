OpenTruth v0.1.0 — Evidence Memory Foundation

Local-first evidence memory for Python 3.11+, with SQLite storage, JSON CLI, and nine tools through the official MCP SDK over stdio. No external model, account, database service, or API key is required at runtime.

Includes claims, exact-wording revisions, source metadata and bounded local file copies with SHA-256, attributed evidence relationships, review history, search, conservative numerical comparisons, and JSON export. Evidence assessments belong to specific claim revisions; comparison records retain their original inputs. Six Mermaid diagrams and four entirely synthetic scientific scenarios document the workflow.

Validation on Python 3.12.14: 52 tests passed, Ruff passed, four synthetic scenarios passed, sdist/wheel build passed, and the independently installed wheel passed an evidence/revision/persistence smoke test. All nine MCP tools were exercised through a real client/server stdio session. All six Mermaid sources passed syntax parsing.

Limits: evidence registration is not independent scientific verification. No semantic contradiction inference, remote MCP transport, authentication, or multi-user access control is provided. ChatGPT connectivity, GitHub rendering, and remote CI status were not verified. Chromium policy blocked local visual rendering; the GitHub API was denied by the network proxy. Coverage was not measured. Python 3.11/3.13 checks are configured in CI but were not executed locally.

See README.md and docs/validation-report.md for installation, validation, compatibility notes, and limitations. No PyPI publication is claimed.
