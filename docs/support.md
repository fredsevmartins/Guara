# Support and project status

Guara is an early-stage open-source local evidence toolkit. Version 0.1.3 is publicly available
under MIT. It has automated tests and documented boundaries; it does not offer a service-level
agreement, guaranteed response times, or commercial support commitment.

## Find the right channel

| Need | Channel |
| --- | --- |
| Installation or usage help | [Troubleshooting](troubleshooting.md), then a [GitHub issue](https://github.com/fredsevmartins/Guara/issues) with a synthetic reproduction |
| Reproducible defect | [Bug report form](https://github.com/fredsevmartins/Guara/issues/new?template=bug_report.md) |
| Scientific comparison/model concern | [Scientific validation issue](https://github.com/fredsevmartins/Guara/issues/new?template=scientific_validation.md) or [evidence-model issue](https://github.com/fredsevmartins/Guara/issues/new?template=evidence_model.md) |
| Feature proposal | [Feature request](https://github.com/fredsevmartins/Guara/issues/new?template=feature_request.md) |
| Security vulnerability | Follow the private-reporting route in [SECURITY.md](../SECURITY.md) |
| Conduct concern | Follow [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) privately |

Search existing issues before filing another. No separate support email, chat workspace, or
GitHub Discussions availability is claimed. Public issues are unsuitable for private evidence.

## Useful bug reports

Include installed version, Python/OS, interface (CLI/Python/MCP), minimal commands or code,
expected versus actual results, and sanitized errors/exit codes. State whether the source was
metadata-only or a copied local file. If relevant, include synthetic context/units, migration
history, and whether backup restoration reproduces the problem. Do not attach an evidence database
or archive unless all contents and metadata are suitable for public disclosure.

## Versions and compatibility

Use release notes for the version you installed; `main` documentation can include corrections
made after a release. [The v0.1.3 documentation snapshot](https://github.com/fredsevmartins/Guara/tree/v0.1.3/docs)
is preserved by its tag. Documentation updates do not replace an existing release archive.
Record the version used in analyses and citations. The product is Guara, while the package and
command remain `opentruth`. APIs are early-stage; no permanent compatibility guarantee is made.
Read release/migration notes and back up before upgrades.

Public downloads are in [GitHub Releases](https://github.com/fredsevmartins/Guara/releases).
PyPI publication is not assumed. Future README roadmap items are plans, not implemented features
or delivery promises. For contributing, see [CONTRIBUTING.md](../CONTRIBUTING.md).
