# FAQ

**Does support mean true?** No. It means someone explicitly registered a SUPPORTS relationship.

**Is a DOI verified?** No. It is stored metadata; no network lookup occurs.

**Can an accepted claim still conflict?** Yes. Reviews record human use decisions; they do not
change comparison rules or erase contrary evidence.

**Does AI provenance become verified?** No. Provenance remains explicit and user-supplied.

**Can I work offline?** Yes after installing dependencies. No runtime external API is required.

**What happens on revision?** The old wording stays in claim_revisions and audit events; current
review status returns to NEEDS_REVIEW. Prior evidence links remain registered against the claim ID,
so reviewers should reconsider their applicability to changed wording.
